# Supplementary research scripts

These are optional investigations and **not required** to reproduce the final Single/Dual baseline. The six calibration scripts study parameter sensitivity, while `flatness/` contains a separate hybrid feedforward experiment. The primary executable source lives in `../src/`.

For standalone experimentation set the MATLAB path appropriately, e.g. `addpath(fullfile(pwd,'src'))` from the repository root. Run experiments only after reading their header comments and checking assumptions. The published baseline values are defined by `src/comet_parameters.m`.
